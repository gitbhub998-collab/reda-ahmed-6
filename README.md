# Reda Ahmed | Portfolio

A personal portfolio featuring railway operations, a fire alarm system demonstration, and a solar-powered vehicle prototype.

## Project files

- `index.html` contains the portfolio content.
- `styles.css` and `script.js` provide styling and interactions.
- `assets/` contains profile photos and project images.
- `favicon.svg` contains the RA monogram.

This is a static site built with HTML, CSS, and JavaScript. It has no dependencies or build step.

## Deploy with GitHub Pages

1. Upload the project files to the repository's `main` branch.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.

GitHub Pages will serve `index.html` and the referenced assets directly.

## Deploy with Vercel

Import the repository using the **Other** framework preset. Leave the build command empty and set the output directory to `.`. The included `vercel.json` provides the output settings.
